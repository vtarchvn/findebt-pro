# User guide

1. Mở Web App bằng Google, nhập tên doanh nghiệp, Khởi tạo.
2. Tạo khách hàng/NCC và hạn mức.
3. Tạo chứng từ phải thu/phải trả; xem cảnh báo vượt hạn mức.
4. Ghi nhận thu/trả, chọn chứng từ để phân bổ.
5. Với phải thu còn dư, bấm biểu tượng QR; với khách đã hẹn, tạo Lời hẹn.
6. Tạo PDF/CSV/backup trong Báo cáo. Bật trigger trong Nhắc nợ để chạy tự động.

Không sửa trực tiếp sheet tài chính khi Web App đang sử dụng. Nếu sai giao dịch, dùng hủy/void và ghi lại giao dịch đúng.
